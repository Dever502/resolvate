# Панель операторов

Единственная веб-панель доступна по `/console/` в том же приложении и на том же порту, что и API.
Она построена на Vue; исходники и команды разработки — в [frontend/README.md](../frontend/README.md).

Навигация: [вход](#запуск), [права](#права-и-api), [управление](#администрирование-в-панели),
[ответы и черновики](#ответы-и-черновики), [готовые ответы](#готовые-ответы-и-личное-меню),
[хранение истории](#история-события-и-хранение).

## Возможности

Панель объединяет переписку, поиск, общие папки, карточку клиента, готовые ответы и управление
проектами и сотрудниками. На телефоне список и диалог показываются по очереди.
История и права хранятся на сервере; локально сохраняются только рабочие черновики и попытки отправки.

## Запуск

Откройте `https://ваш-домен/console/` и войдите выданным аккаунтом. Отдельного флага включения нет.
На новой установке администратор сначала выполняет
[установку и создание первого аккаунта](OPERATIONS.md#быстрый-запуск), затем создаёт проект в панели.
Первичный пароль задаётся интерактивно (12–128 символов); повторный bootstrap запрещён.
Для запуска из исходников нужна [сборка фронтенда](../frontend/README.md#быстрый-старт).

## Права и API

- Единственный администратор установки управляет аккаунтами и проектами. Доступ к переписке
  не возникает автоматически: нужно явное членство, выдача себе доступа аудируется.
- Единственный администратор проекта настраивает подключения и управляет операторами проекта,
  но не аккаунтами установки. Поиск кандидатов возвращает только ID, имя и логин активных
  сотрудников, до 50 результатов, без секретов и членств в других проектах.
- Оператор работает только с проектами, доступ к которым ему явно выдан. Отзыв членства
  не удаляет переписку и не влияет на остальные проекты.
- Передача администрирования атомарна; отключение проекта сохраняет его данные.
- Для Telegram нужны Telegram ID сотрудника и доступ к проекту. Членство в группе само по себе
  не даёт права отправлять ответы через бота. Чтение группы контролирует Telegram: состав
  приватной Forum-группы администратор обслуживает отдельно.

API панели использует `/console/login`, `/console/me`, `/console/logout`, `/console/accounts`
и `/console/projects`. Бизнес-запросы проекта идут на `/console/projects/<project-id>/...`.
Cookie-сессия действует 12 часов; изменяющие запросы требуют корректных Origin и `X-CSRF-Token`.
Создание аккаунтов не открыто для анонимов. Отключение аккаунта отзывает его сессии.

Web Support API и Operator API доступны по `/projects/<project-id>/api/v1/...` и используют
отдельные ключи. Cookie панели не заменяет эти ключи, ключи не заменяют вход в панель.
API-ключи сайта нельзя отдавать клиентскому браузеру.

Логотип загружается на экране проекта и принимается только как PNG/JPEG/WebP до 2 MiB,
нормализуется до PNG 512×512 без метаданных; SVG и анимация запрещены.
Файлы проектов и их права изолированы, backend-проверки не зависят от наличия UI.

При потере доступа к администратору установки на сервере можно выполнить:

```bash
sh scripts/production-compose.sh exec resolvate python -m resolvate.console_admin existing-login --recover
```

Команда задаёт новый пароль интерактивно и передаёт управление существующему аккаунту.
Сессии прежнего и нового администратора отзываются, действие записывается в `access_audit`.
Не передавайте пароли аргументами командной строки.

## Администрирование в панели

На широком экране меню «Управление» находится в шапке; на телефоне действия доступны
через боковое меню. Администратор установки видит «Проекты» и «Сотрудники», администратор
проекта — «Проекты». Скрытие пунктов — только удобство: каждое действие
проверяет сервер, ответ 403 или 409 показывается в окне без потери введённых данных.

- «Проекты»: список с состоянием, ролью и администратором, создание (новый проект выключен), включение
  (сервер требует настроенных бота и группы) и выключение с подтверждением, выдача доступа себе.
  «Настроить» открывает экран проекта: «Участники» (поиск среди кандидатов сервера, до 50, выдача
  и отзыв доступа, смена администратора проекта) и «Подключения» (только администратор проекта).
- «Подключения» — все поля проекта из `PROJECT_FIELDS`: бот и группа, Web API, Operator API,
  Remnawave, webhook, а в разделе «Дополнительно» — лимиты сообщений, ротация тем и сроки хранения
  архива. Сохранённые ключи не показываются, пустое поле ключа оставляет прежний. Сохранение явное;
  уход с несохранёнными изменениями требует подтверждения.
- «Логотип» (только администратор проекта): текущий логотип, предпросмотр выбранного файла, загрузка или замена, удаление с подтверждением. После ответа
  сервера логотип меняется в шапке и списках без перезагрузки.
- «Сотрудники»: аккаунты с ролью, состоянием, Telegram ID и проектами, которыми они управляют;
  создание оператора, отключение (с подтверждением; это не удаление) и включение, Telegram ID,
  сброс пароля (новый пароль задаёт администратор, подтверждая своим текущим паролем; сессии
  сотрудника завершаются) и передача управления установкой. При передаче сервер завершает сессии
  обоих аккаунтов, панель возвращается к форме входа и называет нового администратора.
- «Сменить пароль» в меню аккаунта: текущий пароль, новый и повтор. Сервер завершает все сессии
  аккаунта, поэтому после смены панель возвращается к форме входа с подтверждением. Пароли не
  попадают в URL, сообщения и состояние, которое переживает закрытие окна.
- Пустая рабочая область различает: проекты ещё не созданы, доступа к переписке нет, доступные
  проекты выключены, список не загрузился. Следующий шаг зависит от роли.

## Ответы и черновики

В ответ можно добавить до пяти файлов: кнопкой прикрепления, перетаскиванием на панель диалога
или вставкой из буфера без текста. Поддерживаются JPEG/PNG/WebP, MP4/MOV, PDF и OGG/Opus,
каждый до 20 MiB. Фотографии имеют миниатюру; видео, PDF и аудио — карточку с именем и размером.
Видео до отправки показывается иконкой, не кадром. Файл можно убрать до его отправки.

Файлы отправляются последовательно отдельными запросами, не Telegram-альбомом и не атомарным
пакетом. Текст сопровождает первый файл: до 800 символов с вложением, до 3900 без него.
Enter отправляет, Shift+Enter добавляет строку; подтверждение IME само по себе не отправляет ответ.
«Остановить» прекращает очередь после текущего файла; уже принятое сервером не отзывается.
Ошибка останавливает очередь и оставляет неотправленные файлы. При неизвестном результате повтор
использует исходные данные и тот же ключ идемпотентности. Принятие сервером не означает доставку
в Telegram — статус доставки показан в истории.

Черновики и неизвестные попытки сохраняются в IndexedDB отдельно по аккаунту, проекту и диалогу.
Перезагрузка восстанавливает их, но не отправляет автоматически. Вкладка также помнит выбранные
проект и диалог. Отказ браузерного хранилища сопровождается предупреждением: сохранность после
перезагрузки в этом случае не гарантируется. Явный выход удаляет локальную работу аккаунта
после подтверждения; истечение сессии оставляет её для следующего входа тем же аккаунтом.
Это данные браузера на данном устройстве, не серверные черновики и не межустройственная синхронизация.
Текст и файлы черновиков могут содержать клиентские данные: на общем устройстве используйте явный
выход из аккаунта, а не только закрытие вкладки.

## Готовые ответы и личное меню

Каталог открывается из шапки, на телефоне — из бокового меню. В нём можно создавать группы
и ответы, искать, редактировать, переносить и удалять их. Длинные ответы раскрываются без редактирования. В поле ответа `#` открывает picker только
при пустом черновике; кнопка «Готовые ответы» открывает его и при непустом. Оба способа используют
отдельный поиск: сначала группа, затем ответ. Выбор вставляет текст на запомненное место курсора,
не отправляя его. Escape закрывает picker; Backspace в пустом поиске его не закрывает.

`/` в начале поля открывает доступные команды, ввод названия фильтрует список.
Стрелки выбирают вариант, Enter подставляет его; следующий Enter или «Отправить» выполняет
команду отдельно от клиентского сообщения. Аргументы указаны рядом с названием, например `/gift 30`.
Команды Remnawave видны только при подключённой интеграции; `/resolvepanel` — администратору
проекта или установки с доступом к проекту. Вложения с командами не отправляются.
Список, подсказка аргументов, ошибки и результат показываются в одном всплывающем окне над полем
ответа, как готовые ответы: история и поле не сдвигаются. Escape закрывает список, а без списка —
всё окно; текст команды остаётся. Результат видит только оператор. Ключ команды сохраняется в этой вкладке до новой операции:
повтор запроса и перезагрузка не запускают ту же мутацию заново. При неизвестном результате
сначала проверьте состояние; «Новая команда» требует подтверждения и разрешает новую операцию.

Внутренние заметки (`/note`) видит только команда. В истории заметка — отдельная карточка по центру
с подписью «Внутренняя заметка», автором и временем, а не ответ клиенту. Строка диалога, где последняя
запись — заметка, показывает «Внутренняя заметка», а не её текст.

На широком экране вся строка аккаунта внизу списка — кнопка меню: смена пароля,
прямой выбор System/Light/Dark, выход. На телефоне личные действия находятся в боковом меню.
Выбор темы сохраняется и не закрывает меню; системная тема следует настройке ОС.
Управление проектами и сотрудниками отделено от личных действий.

## История, события и хранение

История и durable-доставка между Telegram и API остаются общими. При закрытии через API панели
клиент получает то же уведомление, что при `/stop`; повторное закрытие не создаёт дубль.
События антиспама внутренние и не попадают в клиентскую историю. Оценка сохраняется одна
на цикл закрытия. Telegram-правки обновляют принятую исходную запись, не отправленные копии.

Обновления приходят автоматически; при недоступности потока событий панель переходит на опрос API.
Вложения доступны только при наличии прав. Проверки файлов не заменяют антивирус.

История подгружается страницами по 50 сообщений; это размер страницы, не срок или предел хранения.
Закрытие обращения завершает его цикл, но не создаёт новый тикет: следующее обращение использует
тот же тикет, а физическая Telegram-тема может смениться при ротации.

Сроки считаются от `archived_at` завершённого архива темы, не от даты сообщения и не от каждого
закрытия обращения: тексты — 60 дней, медиа — 30, сжатие подходящих файлов — после 14 по умолчанию.
Текущий топик, неполный архив, активные ссылки и незавершённые доставки защищают данные;
FAILED-задания защищают архив 30 дней после последней попытки. Поэтому это не правило
«вся переписка старше 60 дней удаляется». При нехватке места допустима ранняя очистка только
подходящих незащищённых архивных медиа. Подробности — [TECHNICAL.md](TECHNICAL.md).
Резервировать нужно PostgreSQL и том данных; бессрочное хранение истории не обещается.
